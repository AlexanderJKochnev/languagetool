# languagetool
## На что обратить внимание
    Порт: В версии образа 6.6 и выше внутренний порт сменился с 8010 на 8081. 
    В compose-файле выше проброс идёт на 8081. Если вам нужен старый порт 8010, добавьте переменную окружения 
    LISTEN_PORT: 8010 и поменяйте маппинг портов на "8010:8010".

    Память: JAVA_XMX: 2g — это запас для стабильной работы. Если у вас мало RAM, можно попробовать 1g, 
    но следите за логами на предмет ошибок OutOfMemoryError.

    N-граммы: В примере они отключены (закомментированы). Для русского языка они могут быть полезны, 
    но их загрузка при старте может занять время. Если решите включить, убедитесь, что в списке есть ru.
